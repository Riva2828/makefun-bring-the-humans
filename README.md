# Bring the humans — iklan make.fun

Entry untuk bounty make.fun `bring-the-humans-01` ($1.000): halaman web yang
mengiklankan make.fun dengan link referral pemiliknya.

- `index.html` — halaman iklan statis (satu file, tanpa aset eksternal; logo
  make.fun dari press kit resmi, di-embed sebagai data URI). Bahasa Indonesia.
  Menampilkan link referral `https://make.fun/r/8e58n6dn` (kode `8e58n6dn`).
- `ad.png` — gambar halaman itu (1200×900), dengan link referral terlihat.
  Dibuat dengan Python/PIL karena VM ini tidak punya headless browser;
  tampilannya mengikuti `index.html` (logo, judul, dan kotak link yang sama).
- `LICENSE` — MIT.

Buka `index.html` di browser untuk melihat halamannya. Halaman ini bukan
situs resmi make.fun — ini iklan buatan peserta bounty.
